# HelloPet (hello-pet)

**Author:** Kozyrev Egor, group M3113

**Plugin Name:** HelloPet

## Description

A simple extension for Visual Studio Code that adds the command
"Say Hello". When invoked, it shows the message "HelloPet: command executed"

## Features

- Command in the Command Palette (Ctrl+Shift+P -> "HelloPet: Say Hello")
- Shows an execution notification
